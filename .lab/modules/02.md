## Module 2 — Add a channel

**Goal:** understand what a parameter definition actually buys you.

### Your task

Add a new channel to the car. Fuel level is a good one:

**1.** Add a `ChannelDef` in [`producer/atlas_lab/channels.py`](producer/atlas_lab/channels.py):

```python
ChannelDef("FuelLevel", "L", "Fuel remaining", "%6.2f", 0, 120),
```

**2.** Emit a value for it from `step()` in [`producer/atlas_lab/lapsim.py`](producer/atlas_lab/lapsim.py):

```python
"FuelLevel": 110.0 - (self.lap_number - 1) * 2.4 - (lap_dist / 3806) * 2.4,
```

Both edits are needed. A declaration with nothing producing values is a channel
that exists and is always empty — which is a surprisingly common way to lose an
afternoon.

Pick a different channel if you prefer. Anything that is not one of the eleven
already there will pass.

### Then watch what you did not have to do

```bash
cd producer && python produce.py --laps 1
cd ../consumer && npm install && npm start
```

Your channel appears in the consumer's output, **with its units**, and the
consumer was never told it exists.

That is because you did not declare "a number called FuelLevel". You declared an
identity, units, a valid range, a display format and a sample rate — and all of
it travels in-band, in the configuration packet, versioned with the session.

On Kafka plus a time-series database, adding a channel means producing the
field, then updating a schema, then updating whatever holds units and ranges,
then telling the dashboard, then telling every other consumer. Those live in
different systems owned by different people, and they drift. The classic symptom
is a chart that has quietly been in the wrong units since someone swapped a
sensor eighteen months ago.

Here, all of it is one act.

### Check it, then submit it

Run the validator here first. It is the *same* code the bot runs, it takes
seconds, and nothing is pushed:

```bash
lab check
```

When it passes:

```bash
lab submit
```

That branches, commits, pushes and opens the pull request against `main` in your
own repository. The bot runs the whole pipeline again on a clean machine,
comments with what happened, and on a pass advances your README and merges.
